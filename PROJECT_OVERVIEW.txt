================================================================================
  🏗️  ARCHITECTURE
================================================================================

MODULAR DESIGN:
- Protocol-based interfaces (app/interfaces.py)
- Plugin registry system (app/registry.py)
- YAML configuration-driven
- Easy component swapping

PIPELINE FLOW:
  Documents → Loader → Chunker → Embedder → Vector Store
                                                     ↓
                              [Query] → Retriever → Reranker → Compressor → Generator
                              
RETRIEVAL STRATEGY:
  - Dense Search (embedding similarity)
  - Sparse Search (BM25 keywords)
  - RRF Fusion (Reciprocal Rank Fusion)
  - Cross-Encoder Reranking (BGE model)
  - Context Compression (token budget)

================================================================================
  📊 COMPONENTS REFERENCE
================================================================================

LOADERS:
  ✓ load.fs          - Filesystem loader (PDF/HTML/TXT/MD)

CHUNKERS:
  ✓ chunk.sentence   - Split at sentence boundaries
  ✓ chunk.semantic   - Topic drift detection
  ✓ chunk.fixed      - Fixed-size windows with overlap

EMBEDDERS:
  ✓ embed.hf         - HuggingFace BGE small (high quality)
  ✓ embed.minilm     - Lightweight MiniLM (fast CPU)

VECTOR STORES:
  ✓ store.chroma     - Persistent Chroma database

RETRIEVERS:
  ✓ retriever.dense  - Embedding-based (semantic)
  ✓ retriever.bm25   - Keyword-based (sparse)
  ✓ retriever.hybrid - Combined with RRF fusion

RERANKERS:
  ✓ rerank.bge       - Cross-encoder (high quality)
  ✓ rerank.noop      - No reranking (fast)

COMPRESSORS:
  ✓ compress.sentences  - Greedy token selection
  ✓ compress.noop       - No compression

GENERATORS:
  ✓ gen.ollama       - Local Ollama LLM
  ✓ gen.mock         - Mock for testing

================================================================================
  💻 USAGE EXAMPLES
================================================================================

INTERACTIVE MODE:
  $ uv run python3 -m app.pipeline
  Q> index              # Build index
  Q> Your question      # Query
  Q> info              # Show config
  Q> exit              # Exit

COMMAND LINE:
  $ uv run python3 -m app.pipeline --index --query "What is this?"

PYTHON API:
  from app.pipeline import RAGPipeline
  
  pipeline = RAGPipeline("app/configs/default.yaml")
  pipeline.index()
  result = pipeline.query("Your question")
  print(result.answer)

CUSTOM CONFIG:
  $ uv run python3 -m app.pipeline --config app/configs/fast.yaml

================================================================================
  🔧 CUSTOMIZATION
================================================================================

SWAP EMBEDDER:
  embedder:
    component: "embed.minilm"
    args:
      model_name: "sentence-transformers/all-MiniLM-L6-v2"

DISABLE RERANKING:
  reranker:
    component: "rerank.noop"
    args:
      top_k: 5

USE DIFFERENT LLM:
  generator:
    component: "gen.ollama"
    args:
      model: "mistral"  # or "llama3.1:8b"

ADJUST CONTEXT BUDGET:
  compressor:
    args:
      token_budget: 12000  # More context
